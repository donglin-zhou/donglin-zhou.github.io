# Zhou Donglin — Personal Website & Portfolio

Static bilingual (Chinese/English) personal website. Hosted on GitHub Pages (user root site `<username>.github.io`).

- `index.html` is the home page and must stay at the repository root.
- Sub-pages: `academic/`, `publications/`, `practice/`, `welfare/`, `hobbies/`.
- `assets/images/` stores all images; `src/` stores styles, scripts and fonts.
- `.nojekyll` tells GitHub Pages to serve files as-is without Jekyll processing.
- `404.html` is the custom not-found page.

After pushing, the site is live at `https://<username>.github.io/`.
